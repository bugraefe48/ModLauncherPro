# 🚀 Mod Launcher Pro

![C#](https://img.shields.io/badge/C%23-239120?style=for-the-badge&logo=c-sharp&logoColor=white)
![.NET](https://img.shields.io/badge/.NET-512BD4?style=for-the-badge&logo=dotnet&logoColor=white)
![WPF](https://img.shields.io/badge/WPF-UI-blue?style=for-the-badge)

**Mod Launcher Pro**, günlük bilgisayar kullanımını otomatikleştirmek, çalışma/oyun ortamlarını tek tuşla hazırlamak ve sistem ayarlarını hızlıca yönetmek için geliştirilmiş modern bir Windows masaüstü (WPF) uygulamasıdır. 
Kendi oluşturduğunuz "Modlar" sayesinde uygulamaları, web sitelerini ve sistem komutlarını klavye kısayollarıyla anında çalıştırabilirsiniz.

## ✨ Öne Çıkan Özellikler

* 🎮 **Mod ve Kısayol Yönetimi:** İstediğiniz uygulamaları, web sitelerini veya kapatılacak görevleri bir "Mod" altında toplayın. Özel klavye kısayolları (Örn: `Ctrl + Shift + 1`) atayarak program arka plandayken bile modları tetikleyin.
* 🎨 **Modern ve Özelleştirilebilir Arayüz:** WPF-UI kullanılarak tasarlanan Mica destekli, yuvarlak hatlı, karanlık/aydınlık tema seçenekli ve 18 farklı renk/özel HEX kodu destekleyen akıcı (Fluent) arayüz.
* ⚙️ **Hızlı Sistem Kontrolü:** Tek tıkla ses seviyesi ayarı, Wi-Fi/Bluetooth açma/kapatma işlemleri ve gece çalışmaları için entegre "Göz Koruma (Gece Işığı) Filtresi".
* ⏱️ **Zaman Yönetimi:** Alarmlı geri sayım sayacı, tur destekli kronometre, ajanda ve yapılacaklar (To-Do) listesi.
* 🚀 **Otomasyon:** Bilgisayar açılışında otomatik çalışan uygulamalar ve favori menü kısayolları.
* 📌 **Sistem Tepsisi (Tray) Desteği:** Kapatıldığında sağ altta (sistem tepsisinde) gizlice çalışmaya devam eden tekil işlem (Single-Instance) mimarisi.

## 🛠️ Kullanılan Teknolojiler
* **Dil:** C#
* **Framework:** .NET (WPF - Windows Presentation Foundation)
* **Kütüphaneler:** [WPF-UI](https://github.com/lepoco/wpfui) (Modern görünüm motoru)
* **Mimari:** Tekil Kopya (Mutex), MVVM tabanlı Veri Bağlama (Data Binding)
* **Paketleme:** Inno Setup
